# Azure Cloud Security Lab

## Overview

This project is a hands-on learning portfolio focused on cloud security fundamentals, security log analysis, threat detection, and remediation.

The lab uses free learning resources and public sample data, alongside simulated security events, to develop practical cloud security skills without requiring a paid Azure subscription.

## Objectives

* Learn Kusto Query Language (KQL) for log analysis.
* Investigate simulated authentication and suspicious activity.
* Develop basic threat detection queries.
* Understand identity and access management (IAM).
* Assess cloud network security configurations.
* Document security risks and remediation recommendations.

## Security and Data Handling

This project is for educational purposes. It uses public sample data and synthetic security events. No real credentials, personal information, customer records, or confidential company data should be committed to this repository.

## Learning Outcomes

The intended outcome is a documented portfolio demonstrating foundational skills in security monitoring, log analysis, threat detection, cloud security assessment, and remediation.
